UTM Builder

Welcome to the UoP RMC UTM builder. This tool has been built to replace the UTM spreadsheet. The logic within remains the same, in that the different UTM parameters in the drop downs are coded to match logical UTM strings. Once you have created your UTM's, either as a singular or as a batch, click the "Generate UTMs" button. The UTM's will then pass to the Shared View tab. The tool will then ask for confirmation if there are no errors highlighted. If there are errors highlighted, then please rectify those.

For any queries, please contact Ben Hunt.
